- `supports_primary`：最高匹配支持JEV候选之一，不提高JEV概率。
- `alternative_candidate`：最高匹配不在JEV候选中，记录复核标记，不硬覆盖主判。
- `tied_candidates`：多个检索类别并列，不通过字典顺序强选。
- `no_match`：无正匹配，不等于反对JEV。
- `unavailable`：该辅助路径缺失；`candidate_only`：只有检索候选，不能代替完整JEV。

`primary_candidates`按默认.80仅作诊断展示；真实业务门槛以 `routing_decision.settings` 为准。`selected_intent`是兼容显示字段，不是多Agent路由输入。低clarity时可能有类别候选，但路由仍会通用兜底。

## 2. 每路怎么计算

BM25：英文和数字词按词取用，中文采用相邻双字片段，避免把整句中文当成一个词。没有人工“关键词→意图”表，也不额外下载分词模型。对75条示例建立 BM25Okapi 索引；每类取最高正分及其示例，不按示例数量求和。无正分时保留零分和空匹配，不强行选 C01。C10示例更多，仍存在最大命中机会不均衡的问题；“这个”等通用字词也会产生错误候选。

Embedding：复用项目 `.env` 的 `EMBEDDING_BASE_URL/API_KEY/MODEL`，使用真实 OpenAI-compatible `/embeddings` 接口，非字符哈希。当前75条示例首次按20、20、20、15分批请求，查询另发一条；每类取最高余弦相似度及示例，保留原始分数。新增C10会生成不同缓存指纹，旧45条缓存不能直接用于新库，后续首次真实调用会重新初始化75条。

缓存：`.cache/intent_embeddings/`；指纹包含 API endpoint、模型名和完整模板内容，不含密钥。后续进程可复用模板向量；模型或模板变更会新建缓存，损坏缓存会重建。进程内锁避免同一识别器并发初始化多次；跨进程仍可能重复初始化。服务侧同名模型静默升级无法仅凭本地指纹察觉，必要时手动更换缓存目录重建。

JEV：一次请求，对话性质四选一 + 独立需求清晰度 noul + 九类 choice。返回三项独立判断、用量和请求 ID。JEV 看最近六条历史，另外两路仅匹配当前消息，因此省略、指代和“历史事项已结束”等情形主要依赖 JEV。这是当前基线的已知差异，不是三路都能理解会话。

## 3. 融合公式

对于每路 s、每类 c：

以下旧公式中的c仅指C01–C09；C10原始分及命中示例单列在 `non_business_evidence`，不参与旧业务归一化。该分阶段兼容不能用于比较业务与非业务的融合可信度；完整十项独立判断及三路辅助关系需要后续改造。

```text
positive[s,c] = max(raw_score[s,c], 0)
share[s,c] = positive[s,c] / sum(positive[s,*])
            若这一整路没有正分，则全部为0

contribution[s,c] = weight[s] * share[s,c]
score[c] = 0.7 * share[JEV,c]
         + 0.2 * share[Embedding,c]
         + 0.1 * share[BM25,c]
```

JEV 的选项概率本身已基本归一化；这里统一算分占比，原始概率仍完整保存。不是把分类 confidence 再乘一遍，也不是复刻原项目仅让各路第一名投票。

融合分是排序分，不是“该意图正确的概率”；即使完整分数之和为1，也没有概率校准含义。余弦分数与 BM25 分数的归一化只得到相对占比，不证明三路证据同等可靠。0.7/0.2/0.1 是待评测的起点，不是已验证的最优权重。

一路服务失败时，该路贡献为0，保留 `source_errors` 和 `degraded`，不把剩余权重重归一化。假设只剩 BM25 且全部匹配 C07，C07 分数仅0.1，而不是1；JEV 失败时清晰度为 null，不能拿其他两路补猜。

输出：九类原始分、每路归一化分、加权贡献、融合排名、前两名差值、对话性质、清晰度、命中示例、各服务用量和错误。仅 BUSINESS 时 `selected_intent` 表示最高分候选，不是路由决定；低清晰度时仍保留业务候选，不宣称已经确认具体诉求。非业务或 JEV 不可用则 `selected_intent=null`，辅助匹配不能覆盖这项限制。完整“JEV主判、另外两路只输出辅助证据”的改革仍未实现，不应从其未完成测试推断生产行为。

## 6. 已发现但暂不展开优化的问题

- 通用问句词及期刊名称会让 BM25 命中无关类别。双诉求的 C02 最高匹配示例甚至是参考文献问法，而不是摘要问法，说明中文双字片段及通用措辞有噪音。
- 整句复合问题只产生一个查询向量，可能稀释某个子意图。真实双诉求里 Embedding 的 C02=0.575660，C03=0.571007，距离很近，不能只靠向量判定两个意图。
- 向量往往对很多类都有正相似度；归一化后贡献分散。相对分数不能代表绝对相关性，也不能证明请求在业务域内。
- 五条示例能覆盖一些表达，不代表覆盖完整类别。真实问法、边界样本、背景提及、否定、域外请求和历史消歧仍需独立评测。
- 尚未校准拒判、复合意图或清晰度阈值；未调用Agent、未返回业务答案。本轮任务的终点就是可解释的意图分数。
