## 范围与布局

交付 `evaluation/reports/agent-rag-overview.html`，单文件离线打开，无服务、CDN 或外网请求。保留原始评测文件，不重跑 RAG、不重新付费判分。

页面采用中文专业仪表盘：深色侧栏、浅色内容区、蓝绿强调色；顶部显示更新时间、来源与覆盖数。桌面左右布局，窄屏折叠为单列。颜色以外同时用文字区分通过、失败、未知与未执行。

三个主分区：

1. RAG 检索：各基线 Recall、NDCG、MRR 等实际已存指标，按语言、基线与运行筛选；逐题展开召回证据及排名。旧 B4 降级结果与真正 no-JEV 实验明确区别。
2. RAG 生成：五项 RAGAS 指标及各自有效数／预期数；逐题查看问题、回答、参考说明、证据、分数和不可用原因。不把 RAGAS 指标均值叫准确率。
3. Agent：端到端、轨迹、表现三层；业务与故障安全分组，展示通过／失败／未知／未执行、阶段耗时、调用量与已知 usage；逐题展开多轮回答及可观察角色／工具事件。

主视图选正式完整运行，历史烟测／诊断运行在历史筛选中单列，不能重复合并计算。可链接原 EvalScope HTML；原生报告被移动时不影响本页已嵌入数据。

## 数据与正确性

“所有数据”指现有评测运行及其逐题结果，不是整个知识库、真实用户数据或凭据。显式列出输入路径、文件哈希、实验条件、运行／判分状态和限制。

- 质量均值只对有效值计算；真实 0 分保留，缺失为不可用，整项缺失显示“—”。
- Agent 同时展示通过／全部预期和通过／可判定；业务、确定性故障与重复实验不能混成一个成功率。
- 不同任务集、语种、缓存条件和裁判版本不能无提示混算。无正式 Agent 结果时显示“未运行”，不伪造占位分。
- 草稿标签／参考答案、同模型裁判、新 Decisions 未校准及 no-JEV 等限制常驻可见。
- 每个输入文件校验失败均显示来源告警，不悄悄少算样本。生成器不修改输入。

## 交互、安全与验收

提供运行／语言／类型／状态筛选、中文搜索、逐题展开和重置；图表用内联 SVG，表格可横向滚动，支持键盘操作。筛选后卡片、图表和表格使用同一子集。

仅从白名单字段输出评测内容，不嵌入环境变量、请求认证头、绝对用户工作区配置或数据库。待评文本作为数据展示，禁止通过 innerHTML 插入。内嵌 JSON 转义 `<`、`>`、`&` 及 Unicode 行分隔符，覆盖 `</script>` 注入测试。

验收需离线测试数值／覆盖一致性、真实 0 与 null 区分、恶意文本、缺失文件、空 Agent 结果；并在浏览器实际检查桌面及窄屏、搜索筛选、展开、原报告链接和无外网依赖。机器测试不能代替视觉检查；如浏览器不可用，明确记录未完成视觉验收。
